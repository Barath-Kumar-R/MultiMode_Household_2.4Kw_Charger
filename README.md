# Multimode Household EV Battery Charger (PFC, interleaved boost)

Academic project, Feb 2025. A PFC-compliant household EV charger with a wide output range, designed and prototyped end to end.

## Result
- **<8% THD across the full load range**
- Output: 24V to 120V at up to 15A (1.8 kW peak)

## Design
- Topology: PID-controlled **interleaved boost** PFC stage
- Control tuned and verified in **MATLAB/Simulink**
- Digital control implemented on **Arduino Mega**

## What's in this repo
- `FAB-demo-004-A.5`: fabrication files
- `PCBA-demo-[NO VARIATIONS]-004-A.5`: assembly files
